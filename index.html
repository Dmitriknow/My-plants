Где взять:
1. Откройте свой проект на supabase.com.
2. Project Settings (⚙) → API.
3. Скопируйте Project URL и anon public key.

Ключ anon безопасен для использования в браузере — доступ к данным ограничен политиками RLS, настроенными в базе.
